# Opción 2: JavaScript + Canvas

1. Sube `index.html` a la raíz de un repositorio GitHub.
2. En Settings → Pages, selecciona la rama `main` y `/ (root)`.
3. Abre la URL publicada.

Esta es una reimplementación estilizada del efecto pointillista en JavaScript. No usa Python, Pygame, NumPy ni librerías externas. Como es una reescritura, algunos detalles visuales y el movimiento no son idénticos al original.
